# Why We Recommend Linux

MSMS projects often use programming tools, scientific libraries and command-line workflows that are easiest to manage in a Linux environment.

We therefore strongly recommend Linux or Windows Subsystem for Linux (WSL) for members doing technical projects.

## Using Windows?

You don't need to switch your entire computer to Linux. If you're using Windows, WSL gives you a Linux environment alongside Windows.

## Using macOS?

You're fine. macOS provides a Unix-based environment and works well with most of the tools we use.

## Which Distribution?
>
> That's upto you.

Ubuntu, Fedora, Debian, Arch, and other distributions can work. Choose one you're comfortable with, or use MSMS as an opportuning to explore Linux.
